# 社区互动与私信

本次沿用现有资讯/文章，不含普通用户发帖。社区页和“我的”提供“我的关注 / 我的收藏 / 私信”；社区还可按昵称“找用户”。

文章详情显示真实点赞/收藏状态与计数，可以取消；作者资料和评论区昵称可点击，进入公开资料后关注/取消关注或给真实用户发文字私信。首次没有署名的资讯统一归属“社区编辑部”，不推测后台编辑账号是C端用户；该发布者未关联真实C端账号时没有私信按钮。关注列表包含已关注的发布者和用户。收藏列表仅展示仍已发布的资讯。

评论最多500字，支持分页和删除自己的评论。私信最多1000字，保留聊天记录、未读数、发送与已读状态，打开聊天页每5秒刷新，离页停止；当前版本没有后台推送、图片/语音私信或群聊。小语AI聊天独立保留。

## 启用

1. 使用本工作区对应的新版后端。需要由后端部署负责人按既有Flyway流程应用`V22__community_interactions.sql`；不要拷贝单个Controller到旧后端，也不要盲目repair。本次开发没有对真实数据库执行DDL。
2. 重新编译小程序。新增页面为community、community-profile、messages；未增加npm依赖、微信插件或额外语音权限。私信仍通过utils/config统一地址请求后端。
3. 使用两个不同C端账号联调。dev模式配置相同`WECHAT_MOCK_FIXED_OPENID`时，两台手机会被识别成同一用户，不能验证互发；使用不同的有效登录身份，不要通过前端伪造userId。用户昵称需要可区分，公开资料页不显示手机号/openid/健康档案。

现在支持在“我的”复制自己的社区号，按对方社区号精确查找，不必依靠昵称区分。真实微信配置与两台手机步骤见[WECHAT-LOGIN.md](WECHAT-LOGIN.md)。私信列表首屏也会每5秒刷新，离页停止。

## 验收

- 账号A点赞、收藏文章，重新进入状态仍保留；B的个人状态独立，计数一致。A在收藏列表能打开文章，取消收藏后列表不再显示，下架文章不可打开。
- A关注发布者或评论用户，“我的关注”能查看并跳转资料；取消后返回列表不再显示。
- A评论，B可见并可点击昵称访问公开资料；B无法删除A的评论，A删除后再次刷新不显示。断网提交失败保留正文，点击重试沿用幂等ID。
- A从B的资料页发消息，B在私信列表看到未读并进入回复；双方聊天页5秒内刷新显示新内容；第三账号C无法读取A/B的消息或更改已读状态。
- 私信发送失败保留草稿，重复点击不重复请求，失败后重试不重复入库；退出/换账号后的晚响应不能显示旧消息，也不能清空新账号草稿。

没有新版接口或数据库迁移时会显示错误和重试，不用本地假数据模拟互动成功。客户端代码及H2回归通过不等于已完成真实MySQL、手机网络和双账号真机验收。
