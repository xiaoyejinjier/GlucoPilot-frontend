# 小程序语言与交互反馈

“我的 → 设置 → 语言”支持简体中文和 English，默认中文。切换立即更新现存页面、自定义导航及组件，以 `appLocale` 保存到本机，不修改业务枚举。页面重新进入会同步语言和原生导航标题，卸载实例从监听集合移除。文章和英文名使用后端独立缓存接口，V39迁移创建缓存表。

页面、按钮、提示、表单选项、九时段标签、图表标签和新手指引使用统一文案表。原生 Toast、Loading、Modal 和 ActionSheet 的界面文本跟随选择，回调、动作索引、默认输入和业务参数保留。微信自身的日期选择器等系统控件仍采用微信/系统语言。

文章与昵称的中文原文保留在原业务字段。英文模式通过 `/localizations/en` 读取独立译文：文章列表显示英文标题和摘要，详情显示英文正文；资料卡显示英文名及中文原名。私信、评论、签名、自定义标签、管理员回复和已有 AI 对话保留原文。内置分类按 code 翻译，不改提交值；糖尿病选择器只翻译显示数组，仍以原索引提交中文业务值。点击小语的英文示例填写对应英文问题，用户修改后发送。自定义法律文本没有对应译文时保留原文。

`utils/content-localization.js` 只给前台可见页面排队，批量读取并按PENDING状态复查；退出页面/切换账号/语言时使旧回调失效。结果写入独立 `contentTranslations`，不覆盖 `news`、`posts`、`userInfo` 或编辑表单。WXS `content()`/`name()` 核对原文精确一致后才显示译文；原文变化会重新请求，服务端每次核查阅读权限和原文hash。失败显示原文和可重试提示，不把原文伪装成已完成翻译。富文本保留原标签/媒体URL，纯文本仍用text渲染。

## 文案维护

1. 编辑 `tools/i18n/en.tsv`：中文键、Tab、英文文案；需要尾随空格时写 `\s`，避免行尾空白。
2. 运行 `node tools/build-i18n.cjs`，生成 `utils/locales/en.js` 和 `utils/i18n.wxs`。二者从同一份表与 `tools/i18n/runtime.txt` 生成，不手改产物。
3. WXML 引入 `/utils/i18n.wxs`，仅在展示层调用 `i18n.t(label, locale)`。模板显式传 `locale`。用户原文、输入 value、data-*、业务判断和接口 payload 不交给翻译。内置分类可使用 `i18n.tag(tag, locale)`；用户自定义 code 不翻译。
4. JS 纯展示使用 `utils/locales/en.t(text, locale)`；语言管理用 `utils/i18n.js`。App 启动时统一包装 Page/Component 生命周期，不复制每页监听器。
5. 运行 `node --test tools/tests/*.test.cjs`，并编译 WXML/WXS/WXSS。新增页面和文本需要同步词表，检查小屏幕及大字号换行。

不引入第三方翻译 SDK 或国际化 SDK。动态文章和英文名由后端使用已配置的文字模型生成并缓存，首次需要等待；模型不可用时保留原文并显示重试提示。两个静态文案运行时合计约 150 KB，`tools` 和 `docs` 已由项目配置排除出上传包；没有文案的图标等模板不额外引入词表。

## 指引与动效

小语是第五步，从左到右为“现在试试 / 跳过 / 下一步”。试用先完成全局指引，再恢复记录页图表并打开独立小语页；下一步只结束指引。跳过和已有缓存页清理继续有效，重复点击不重复导航，设备说明介绍实际的添加/绑定/详情/同步状态功能。

普通控件采用 `utils/motion.wxss` 的 `ui-interactive` / `ui-pressed`，约 160 ms 轻按压；嵌套动作阻止 hover 向父卡片传播，页面布局不变。导航选中图标轻弹约 280 ms。点赞、收藏继续沿用自身组件的独立 pulse，触摸输入/录音、遮罩和滚动容器不添加整体缩放；支持减少动态效果的系统偏好。

信息分类用约240ms图标轻弹、选中短线和180ms颜色过渡，语言设置勾选用220ms反馈；设备弹层用220ms小幅上移淡入，输入区域不挂按压缩放。图片/视频静态封面出现时仅200ms淡入，不改变尺寸。设备和信息列表仅请求期间挂载三点加载提示，管理回复刷新图标仅请求期间旋转，不新增JS计时器、网络请求或动效依赖。

消息数量与红点出现时轻弹一次，数字更新不重新挂载；成功提示统一深蓝底。系统启用`prefers-reduced-motion: reduce`后禁用新增动效，并补齐点赞/收藏、成功提示、提醒弹层及创作页骨架的静态降级，状态文字/选中色继续可见。后续动效优先使用transform/opacity，不给长列表整体加缩放或循环动画。
