# 小程序配色

主色统一为与小语相同的GitHub Primer蓝色，搭配浅灰页面、白色卡片和中性文字；参考[Primer浅色规范](https://primer.style/product/primitives/color/)。

| 用途 | 变量 | 默认色 |
| --- | --- | --- |
| 主按钮、导航选中、链接 | `--brand` | `#0969da` |
| 深色强调 | `--brand-dark` | `#0550ae` |
| 选中项、轻量强调背景 | `--brand-soft` | `#ddf4ff` |
| 蓝色边框 | `--brand-line` | `#b6d7fb` |
| 页面背景、次级输入背景 | `--bg` / `--surface-subtle` | `#f6f8fa` |
| 卡片 | `--surface` | `#ffffff` |
| 正文 | `--ink` | `#1f2328` |
| 次级正文 | `--ink-soft` | `#3d4854` |
| 说明文字 | `--muted` | `#59636e` |
| 时间、辅助信息 | `--hint` | `#6e7781` |
| 分割线 | `--line` | `#d1d9e0` |

`app.wxss`提供默认值，`utils/display.js`通过页面根节点`displayStyle`覆盖品牌变量和字号。为兼容已保存的本地/服务端偏好，保留`green`、`teal`、`simple`三个内部ID：展示名称分别为“经典蓝”“静谧蓝”“简洁白”，不变更接口或数据库枚举。Canvas继续通过`getTheme()`获取主色。

- 记录：九时段节点一律采用`#f6f8fa`灰底和`#d1d9e0`边框，正常状态点为蓝色，偏高橙色、异常红色。低血糖选择详情仍为红色，不把状态信息全部抹为灰色。
- 统计：导航、指标、月份选中和正常日历等级使用蓝色；指标卡以灰底为主，保留原有记录档位和异常语义。曲线跟随主题主色。
- 社区：淡蓝顶部标题卡、白色分享/文章卡、蓝色快捷入口和标签；点赞粉红、收藏金色保持不变。本人文章/公开主页同步去除绿色装饰。
- 我的：主要调整个人资料卡为浅蓝背景、蓝灰文字，其他分区、图标布局及收藏金色/关注紫色装饰保留。既有主色文本跟随全局变为蓝色。
- 设备：从GitHub合入设备管理功能后沿用浅灰/白卡与蓝色按钮，普通文字采用蓝色层次。绑定设备页使用`--device-*`隔离变量；错误及警告保留语义颜色。设备管理页预留底部自定义导航高度。
- 小语：使用`--voice-*`控制浅灰背景、白色欢迎卡片/助手气泡、浅蓝用户气泡和蓝色按钮；语音面板优先读取这些变量，其余页面回落到全局主题。底部导航“小语”名称保持原`#4777ad`蓝色，字号偏好照常生效。
