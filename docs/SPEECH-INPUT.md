# 小语语音输入

点击输入框左侧语音图标，输入框先变为“按住说话”，此时不打开弹窗、不启动麦克风。按住按钮才录音并显示“松开结束”的提示；松手后自动停止并转成文字（最多60秒自动结束）。识别结果可以修改，选择“确认发送”才作为普通文本发送；选择“重新录音”回到按住说话，需要再次按住才录音。左侧键盘图标可切回文字输入，已有草稿保留并合并到确认框。

首次麦克风授权期间若已松手，只完成授权，不在授权后启动录音；授权后请再次按住说话。触摸取消或离页会丢弃当前录音，不转写、不发送。

小程序使用微信原生RecorderManager录制单声道16kHz、48kbps MP3，通过自己的后端`POST /api/v1/speech-transcriptions`转写，不需要微信同声传译插件或OSS。音频不登记为媒体、不进入聊天数据库；离页停止录音，完成读取/取消后删除临时录音文件。发送后的文字继续使用现有聊天历史、会话和SSE链路。

## 启用

1. 部署本次后端代码并重启，重新编译小程序。旧后端没有此接口，前端会明确提示更新后端。
2. 后端配置`AI_SPEECH_API_KEY`，或在已忽略的application-local.yaml中填写`ai.speech.api-key`。缺省复用环境变量/本地yaml配置的`ai.vision.api-key`；不会读取后台模型表中加密的视觉密钥。不要在小程序代码中填写密钥。
3. 默认模型为`qwen3-asr-flash`，接口为百炼北京OpenAI兼容端点。账号需有该模型调用权限，密钥和接口地域一致；可通过`AI_SPEECH_MODEL`、`AI_SPEECH_BASE_URL`覆盖。`ai.speech.enabled=false`可以单独停用语音。未配密钥只影响语音转写，不影响应用启动。
4. 小程序已声明`scope.record`用途；微信公众平台隐私保护指引中需按实际功能声明麦克风/录音与语音转写用途，手机首次使用允许录音权限。开发者工具无法替代手机的权限和录音验收。

接入协议依据：[百炼Qwen录音文件识别官方文档](https://help.aliyun.com/zh/model-studio/recording-file-recognition-qwen)，使用`input_audio`及Base64音频，服务端45秒超时，小程序请求60秒超时。配置缺失、无语音、识别失败或权限拒绝均显示真实原因，不返回假识别文本。

## 验收

检查点击语音仅切换按住说话、按住显示提示/松手停止、首次授权期间松手、短按/系统触摸取消、录制后审阅/修改、重录返回按住说话、已有草稿、60秒自动停止、后台中断、识别失败及重试、退出和切换账号/会话、键盘展开后确认按钮位置。只有确认发送后出现用户气泡；取消、失败和识别完成本身均不创建消息。
